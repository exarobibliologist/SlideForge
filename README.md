# SlideForge
The slideshow viewer that evolved into something much more...

# The Story So Far
SlideForge started out as an image slideshow viewer. I got frustrated by the difficulties I was having with a slideshow program on my computer, where all the slideshow options were locked behind a paywall.

So I thought, “Well, maybe I could make one of my own.” I was inspired by the project ArtCraft, which was designed by AI. So I fired up my own AI, Google Gemini, and we started working on this project together to make the best slideshow program I needed.

Version 1 and 1.1 of SlideForge dealt exclusively with images (.jpg, .png) and image slideshows with actual nice slideshow effects. 

Once I had successfully made the slideshow program, and I had a really good grasp on how to do the slideshow and make all the effects, one day I was thinking, “I wonder what else I can add to this program?”

So then I started looking at video codecs as well. From version 1.3+ I added VLC media codecs, so that way it could do video as well.

Now I wanted to be the best media player that I could create. I added VLC media codecs and made it so that when you clicked on a video folder, it would show all the videos in the slideshow viewer as little thumbnails (just like it did for images in an image folder).

Now, I had a great video-player and slideshow-player!

But, I wanted to go further... I was currently using two media players on my computer—VLC Media Player (best program I've seen for frame-by-frame playback and video image capture, along with playing practically every damn video codec out there...) and SMplayer (best for searching subtitles for the current video), but I was convinced I could do it all in SlideForge with a little tinkering.

I was already using VLC media codecs, so that was half the battle. From version 1.4+, I began focusing on adding more of the SM player ideas to the app. For example, I added a subtitle searcher. Once you enter/save your API key for OpenSubtitles into the SlideForge program, you could add subtitles directly to the video folder. Now it works like SMPlayer too.

At this point, I have a slideshow player that also does video codecs and can look up subtitles for those videos, but I wanted to go further. At this point, I decided, could it also do all media?

VLC already had the ability to play audio files, but my program, even though it used VLC codecs, was only set up for images or video. Version 1.7+ I decided to unlock everything. So now my program can do images, videos, and audio files.
